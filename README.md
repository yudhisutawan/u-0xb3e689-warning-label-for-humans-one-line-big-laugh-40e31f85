— write the funniest single-line safety warning label that should come
printed on every human being, at most 160 characters.

## The line (149 characters)

> WARNING: Do not feed after midnight, before coffee, or during a meeting. Side effects include sighing, eye-rolling, and replying "per my last email".

## How it was chosen

10 candidates, full round-robin tournament (45 pairs), judged head-to-head
with the competition's own judge brief (criteria in order: on-subject
warning label, laugh in one read with the turn in the last few words,
recognition, label wording, ≤160 chars / one idea). See
[TOURNAMENT.md](TOURNAMENT.md) and [CANDIDATES.md](CANDIDATES.md).

- Candidate **F** won the round-robin **8-1** (only loss: C, margin 1).
- Refined variant **F2** (added "eye-rolling" to make the side-effects
  list a proper triple) beat F (margin 1), beat runner-up I (margin 1),
  and lost only to C (margin 1) — **9-1 against the field**, the best
  record of any candidate. F2 is the submitted line.

## Run

```sh
python3 -S -P main.py   # writes entry.txt to $MAKEFUN_OUTPUT_DIR (or /output)
```

Stdlib only; writes nothing to the repository directory.
